# TetraCore

We make [LinkPilot](https://uselinkpilot.com), a service for sharing passwords, API keys and files as links that open once and then destroy themselves, plus branded short links with click analytics. Secrets are encrypted in your browser or your process before they are sent, so LinkPilot never holds the key.

## LinkPilot open source

| Repo | What it is | Install |
|---|---|---|
| [linkpilot-cli](https://github.com/TetraCoreHQ/linkpilot-cli) | TypeScript SDK and command-line tool for the LinkPilot API | `npm i -g linkpilot` or `npm i @uselinkpilot/sdk` |
| [linkpilot-mcp](https://github.com/TetraCoreHQ/linkpilot-mcp) | MCP server so AI assistants can create secret links and short links | `npx -y @uselinkpilot/mcp` |

LinkPilot also ships as a [Chrome extension](https://chromewebstore.google.com/detail/linkpilot-short-links-and/mnmppadihpcncicldpkmgknhnjkondad), a [Firefox add-on](https://addons.mozilla.org/en-US/firefox/addon/uselinkpilot/), a [Raycast extension](https://www.raycast.com/tetracorellc/linkpilot) and a Slack app. The full list is at [uselinkpilot.com/apps](https://uselinkpilot.com/apps).
